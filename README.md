
# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application that allows customers to browse plants, explore different plant categories, and add plants to a shopping cart.

## Features
- Landing page with a Get Started button
- Plant listings organized into categories
- Add plants to the shopping cart
- Increase and decrease item quantities
- Remove items from the cart
- Calculate the total cost of items in the cart
- Continue shopping from the cart page

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Purpose
This project demonstrates the development of an interactive shopping application using React and Redux for state management.
